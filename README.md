# 未来のご縁帳
今日のご縁を、未来につなぐ。名刺の写真・ツーショット・声で、出会った人を「顔か声」で思い出せるノートです。

- 公開ページ：https://mirai-goen-cho.pages.dev/
- データは、使う人のスマホの中だけに保存します（サーバーには保存しません）
- 「本質」は、誕生日の日付だけをサーバーに送って計算します。計算表は Cloudflare の秘密の設定にだけ置いています

## 中身
- public/index.html：画面
- functions/api/honshitsu.js：本質を返すサーバー側の処理（Cloudflare Pages Functions）
